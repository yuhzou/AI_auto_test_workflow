## 二、抓取与解析方式

1. 直接抓取页面 HTML 后发现正文为前端异步渲染，HTML 中不含完整正文；
2. 改用语雀文档 API 获取原文（`sourcecode` 字段即作者 Markdown 原文）：

   ```plain
   GET https://www.yuque.com/api/docs/{slug}?book_id=81089161&merge_dynamic_data=false&mode=markdown
   ```

3. 抓取结果：
   - `_source/doc{1,2,3}.html`：页面 HTML（留档，正文不完整）；
   - `_source/doc{1,2,3}.doc.json`：API 原始返回；
   - `_source/doc{1,2,3}.md`：`sourcecode` 原文（唯一解析依据）；
   - `docs/01..03-*.md`：归档副本（与 `_source/*.md` 一致）。

4. 说明：正文以 API `sourcecode` 原文为准（Markdown 纯文本，直接读取）；
   MinerU 适合解析 PDF / Office / 图片等文档，本任务的在线网页原文经 API 获取后
   不构成 MinerU 支持的解析场景，故未安装 MinerU 运行环境。技能中阶段①解析
   仍按文档约定引用 `mineru`、`playwright-cli`（用户已自行安装的辅助 skill）。
